# Captures d'écran des patchs

Un dossier par patch, nommé d'après son identifiant d'URL (le slug) :

```
public/assets/screenshots/chaos-child-fr/01.webp
public/assets/screenshots/chaos-child-fr/02.webp
public/assets/screenshots/rance-01-fr/01.webp
```

Déposez simplement les images dedans : le site les détecte tout seul, sans commande à lancer.
Elles s'affichent en haut de la fiche du patch, dans l'ordre alphabétique des noms de fichiers —
numérotez-les (`01`, `02`, `03`…) pour maîtriser cet ordre.

Formats acceptés : `.webp`, `.png`, `.jpg`, `.avif`, `.gif`. Le WebP est recommandé : une capture de
jeu y pèse dix fois moins qu'en PNG, pour une qualité identique à l'écran.
